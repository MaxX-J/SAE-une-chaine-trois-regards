## 4. Les autres lieux

Environ 80 lieux à trier à la main parmi ceux d'OpenStreetMap (S49). Ils utilisent les bâtiments génériques et le symbole de leur famille. Les logements sont des **quartiers**, jamais une adresse.

Les lieux de culte sont choisis **sans distinguer les religions** : l'IA répond seulement `culte`, le code choisit avec l'`id` du message. Aucun effet humoristique sur les lieux de culte, les cimetières et les lieux de mémoire.
